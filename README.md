# AFTER THE HIGH

**Drug awareness, overdose prevention, recovery, remembrance, and real help resources — created by Crystal.**

Live site: https://y2kbeatzz-dot.github.io/After-The-High/

AFTER THE HIGH is an interactive awareness project covering fentanyl, cocaine, meth, opioids, lean/codeine, benzodiazepines, MDMA, ketamine, cannabis/THC, overdose warning signs, naloxone, recovery, music, and support resources.
